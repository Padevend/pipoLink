# Reusable Components

The `src/shared/ui` folder contains generic, reusable components. These components do not hold any business logic.

## Button
A highly customizable button component supporting different variants (primary, secondary, outline, ghost) and states (loading, disabled).

## Input
A text input component with built-in label, error message rendering, and optional left/right icons (e.g., for password visibility toggling).

## Header
A standard top-navigation header component used across screens. Supports titles, subtitles, and customizable right/left actions.

## Loader
A simple spinner or skeleton component used as a placeholder during asynchronous operations.

## Avatar
A rounded image component that automatically falls back to the user's initials with a distinct background color if the image URL is not provided.
